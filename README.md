MyTask

A simple task management web application built with Hibernate, Jakarta Servlets/JSP and MySQL. Users can add, view, update and delete tasks (full CRUD).

Features
Add a task with a title and content
View all tasks (newest first)
Update an existing task
Delete a task (POST request with a confirmation prompt)
Unicode support, so tasks can be written in any language
Input validation and HTML escaping to prevent XSS
Tech Stack
Layer	Technology
Language	Java
ORM	Hibernate 6.4
Web	Jakarta Servlet 6.0, JSP
Database	MySQL 8
Build tool	Maven (WAR packaging)
Server	Apache Tomcat 10.1+
Frontend	HTML, Bootstrap 4
Prerequisites
JDK 17 or newer
Apache Maven 3.8+ (or Eclipse with the built-in Maven support)
MySQL 8 running on localhost:3306
Apache Tomcat 10.1 or newer (Tomcat 9 will not work because the project uses the jakarta.* namespace)
Getting Started
Clone the repository
bash
   git clone https://github.com/<your-username>/MyTask.git
   cd MyTask
Configure the database Open src/main/resources/hibernate.cfg.xml and set your MySQL username and password:
xml
   <property name="hibernate.connection.username">root</property>
   <property name="hibernate.connection.password"></property>

The database sampledb and the task table are created automatically on first run.

Build the project
bash
   mvn clean package

This creates target/MyTask.war.

Deploy Copy MyTask.war to Tomcat's webapps folder and start Tomcat, or run the project from Eclipse using Run As > Run on Server.
Open the app http://localhost:8080/MyTask/
Running in Eclipse
File > Import > Maven > Existing Maven Projects, then select the project folder
Right-click the project > Maven > Update Project
Right-click the project > Run As > Run on Server > Tomcat v10.1
